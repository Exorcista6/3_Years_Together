## Archivos importantes

### HTML

Archivo principal:

`index.html`

Ahí están las pantallas de la web.

---

### CSS

Archivo de estilos:

`style.css`

Ahí se editan colores, tamaños, diseño responsive, botones, tarjetas y efectos visuales.

---

### JavaScript

Archivo de lógica:

`script.js`

Ahí se editan:
- Respuestas del quiz.
- Validación de fecha.
- Música.
- Cambio de pantallas.
- Lógica del quiz.
- Desbloqueo del video final.
